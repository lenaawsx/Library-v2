
# Личная библиотека книг

**Автор:** Родюкова Елена  
**Группа:** ФТ24ДР62ПИ2  
**Тема:** Личная библиотека — учёт книг, статусов чтения и пользовательских заметок.

## Описание проекта

Приложение предназначено для ведения личной коллекции книг. Оно позволяет просматривать список книг, отслеживать статус чтения, выставлять оценки и сохранять личные заметки.

### Основные возможности

- Просмотр списка книг и подробной информации о каждой книге.
- Фильтрация книг по статусу чтения.
- Добавление новых книг.
- Редактирование информации о книгах.
- Удаление книг с подтверждением действия.
- Указание автора, жанра, статуса чтения, оценки и заметки.
- Проверка обязательных полей и допустимого диапазона оценки.
- Навигация между страницами приложения.

Изменения хранятся в состоянии React и не сохраняются после обновления страницы.

## Технологический стек

- React Router
