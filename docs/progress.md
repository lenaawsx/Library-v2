## Лабораторная работа № 3

### Выполненные шаги
1. Организовано хранение списка книг в состоянии React с помощью `useState`.
2. Реализовано добавление новых книг с проверкой обязательных полей.
3. Добавлено редактирование информации о книгах.
4. Реализовано удаление книг с подтверждением действия.
5. Добавлен фильтр книг по статусу чтения и возможность сброса фильтра.
6. Настроена передача данных и функций между компонентами через props.
7. Реализовано неизменяемое обновление состояния при добавлении, редактировании и удалении книг.
8. Добавлено сообщение о временном хранении изменений.
9. Обработаны ситуации отсутствия книг и некорректных данных.

### Результаты проверки
- Проверено добавление, редактирование и удаление книг.
- Проверена отмена редактирования без сохранения изменений.
- Проверена фильтрация книг по статусу чтения.
- Изменения хранятся в состоянии React и сбрасываются после обновления страницы.
- Финальная сборка проекта будет проверена командой `npm run build`.
